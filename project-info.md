# Project Information: GalgameManager (PotatoVN)

This document provides a high-level overview of the GalgameManager project, also known as PotatoVN. It is intended to help AI agents and new developers quickly understand the project's structure, components, and purpose.

## 1. Project Overview

*   **Name:** PotatoVN (also known as GalgameManager)
*   **Tagline:** 一款VisualNovel管理工具，旨在为galgame屯屯鼠们提供一个方便的游戏管理平台。 (A Visual Novel management tool, designed to provide a convenient game management platform for visual novel collectors/enthusiasts.)
*   **Purpose:** To provide a convenient game management platform for visual novel enthusiasts.
*   **Key Features (from `README.md`):**
    *   Automatically search for games in folders.
    *   Automatically fetch game information from multiple databases (currently supports Bangumi, Visual Novel Database) and synchronize play status from accounts.
    *   Synchronize game saves with the cloud (this feature requires synchronization software on the computer to sync the save folder, such as OneDrive, NextCloud, Jingoal Cloud, Baidu Cloud Sync, etc.).
    *   Track game playtime and synchronize play count (`PlayCount`) and play time details (`PlayedTime`/`PlayLog`) with the `GalgameManager.Server`.
    *   Automatically extract games from compressed files, identify them, and add them to the game library.
*   **Main Technology Stack:** .NET (C#), WinUI 3 for the client; ASP.NET Core for the server.
*   **Architecture:** MVVM (Model-View-ViewModel).
*   **Development Framework:** Based on a framework generated by TemplateStudio.
*   **Localization:** 
    *   The project uses Crowdin for managing translations.
    *   Supported languages are defined in `GalgameManager/Enums/LanguageEnum.cs` (currently includes Auto, ChineseSimplified, English, Japanese).
    *   Language-specific resources (`Resources.resw`) are located in subdirectories under `GalgameManager/Strings/` (e.g., `en-US/`, `zh-CN/`, `ja-JP/`).
    *   The display names for languages in the settings UI are localized (e.g., "English" in the English UI, "中文" in the Chinese UI, "日本語" in the Japanese UI).
